# Core references

Each skill lists its own sources. These are the cross-cutting frameworks the catalog is aligned with:

- Agent Skills specification: https://agentskills.io/specification and Claude Code skills docs: https://code.claude.com/docs/en/skills
- Claude Code plugin reference: https://code.claude.com/docs/en/plugins-reference
- NIST SP 800-61r3 Incident Response (2025): https://csrc.nist.gov/pubs/sp/800/61/r3/final
- NIST CSF 2.0: https://www.nist.gov/cyberframework
- MITRE ATT&CK (v20 snapshot used for validation): https://attack.mitre.org/
- MITRE ATLAS: https://atlas.mitre.org/
- OWASP ASVS, API Security Top 10 (2023), Top 10 for LLM Applications (2025): https://owasp.org/
- CISA KEV and advisories: https://www.cisa.gov/known-exploited-vulnerabilities-catalog
- CIS Controls v8.1 and Benchmarks: https://www.cisecurity.org/
- Sigma: https://sigmahq.io/ ; YARA: https://yara.readthedocs.io/
